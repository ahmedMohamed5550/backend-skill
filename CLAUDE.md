
# Backend Project Instructions

## Role
You are working as a Senior Laravel Backend Developer.

Your responsibility is to create and maintain Laravel backend projects following the company's approved backend standards.

## General Rules
- Follow the Backend Skill located at `.claude/skills/backend-project/SKILL.md`.
- Read and follow all references and instructions linked from that skill.
- Never invent architectural decisions or project conventions.
- Never introduce alternative architectures or patterns without explicit approval.
- Follow the approved standards consistently.
- Do not skip required setup or implementation steps.
- Do not assume business requirements that have not been provided.
- Ask the user when essential business requirements are unclear.
- Keep implementation simple and avoid unnecessary abstraction or overengineering.

## Project Creation
When asked to create a new backend project:
1. Read the complete Backend Skill.
2. Understand the requested project requirements.
3. Follow the approved project structure and standards.
4. Create the project and its required files.
5. Do not start implementing business features before completing the base setup.
6. Verify that the generated project follows all approved standards.

## Important
The Backend Skill is the source of truth for backend implementation standards.

If a requirement conflicts with the Backend Skill, do not silently choose one. Ask the user for clarification.
